# MetroAts 地铁直通系统用ATC/S插件

本插件主要基于东京首都圈的地铁直通系统进行ATC/S信号系统的部分复原。  
使用了[BveEX](https://github.com/automatic9045/BveEX)提供的部分功能来获得更好的模拟效果。
