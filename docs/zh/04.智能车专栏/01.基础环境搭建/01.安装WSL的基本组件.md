# 安装 WSL 的基本组件

::: info
以下操作对你的 Windows 系统版本有下列要求：<br>Windows 10 版本 2004 及更高版本（内部版本 19041 及更高版本）或 Windows 11<br>如果你不满足以上要求，请参阅：[旧版 WSL 的手动安装步骤 \| Microsoft Learn](https://learn.microsoft.com/zh-cn/windows/wsl/install-manual)
:::

首先，我们先按下 **Win+X**，点击终端管理员，打开终端，进入 **PowerShell**，然后在打开的 **PowerShell** 终端中，输入下方命令：

```bash
wsl --install
```

取决于与 GitHub 之间的网络速度，这个过程可能需要一定时间。此命令将启用运行 WSL 并安装 Linux 的 Ubuntu 分发所需的功能，请耐心等待其安装完成。

因为 WSL 分为 WSL1 和 WSL2 两个版本，我们需要使用支持 Linux GUI 应用的 WSL2，所以请继续在终端中输入下方命令，将 WSL 安装的默认版本设置为 WSL2：

```bash
wsl --set-default-version 2
```

若成功，你将看到以下提示：

![示意图](/origincar/env/wsl/01-image2.webp)

WSL 的 USB 功能需要安装 USB-IPD 组件，请执行下方命令进行安装：

```bash
winget install --interactive --exact dorssel.usbipd-win
```

::: info
有关 WSL 的 USB 功能，请参阅：[连接 USB 设备 \| Microsoft Learn](https://learn.microsoft.com/zh-cn/windows/wsl/connect-usb)
:::

以上组件的安装均需要能够稳定连接至 GitHub 以及微软的网络。

::: warning
如果过于缓慢，请对 GitHub 的访问进行加速后重试。
:::
