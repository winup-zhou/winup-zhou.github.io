# ROS2 安装验证

为了验证我们的安装是否成功，我们可以运行 ROS 官方提供的小乌龟节点进行一下安装验证：

```bash
ros2 run turtlesim turtlesim_node
```

如果你的 WSL 和 ROS 安装正确，你应当能看到一个名为 TurtleSim 的窗口出现，上面有一只小乌龟：

::: info
如果没有出现，请在 WSL Settings &gt; 可选功能中查看是否启用了 Linux GUI 应用。<br>如果没有启用该功能，请启用后重启 WSL。
:::

<img src="/origincar/env/ros2-verify/01-image24.webp" alt="示意图" width="688" />

然后我们再新建一个终端页面，启动小乌龟节点的键盘控制程序：

```bash
ros2 run turtlesim turtle_teleop_key
```

使用键盘控制小乌龟的移动，如果小乌龟能够正常进行移动，则说明 ROS 的基本安装没有问题。

<img src="/origincar/env/ros2-verify/02-image25.webp" alt="示意图" width="688" />
