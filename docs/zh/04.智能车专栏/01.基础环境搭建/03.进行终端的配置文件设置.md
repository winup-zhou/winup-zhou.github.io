# 进行终端的配置文件设置

为了保证后续开发能够便利的开启 WSL 系统，我们建议安装 Windows 终端应用程序，且我们需要进行一些设置：

::: info
Windows 终端应用程序在 Windows 11 中默认已安装，图标如图所示：![示意图](/origincar/env/terminal-config/01-image13.webp)<br>Windows 10 用户可能需要手动进行安装操作：[Windows Terminal - Windows 官方下载 \| 微软应用商店 \| Microsoft Store](https://apps.microsoft.com/detail/9n0dx20hk701?hl=zh-cn&gl=CN)
:::

![示意图](/origincar/env/terminal-config/02-image14.webp)

我们将默认配置文件设置为如图所示：

![示意图](/origincar/env/terminal-config/03-image15.webp)

然后，点击进入 Windows PowerShell 的配置文件，开启以管理员身份运行此配置文件：

![示意图](/origincar/env/terminal-config/04-image16.webp)

保存设置并退出。
