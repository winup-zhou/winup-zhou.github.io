# 开发板初次设置

::: warning
以下操作需要事先连接好无线网络。
:::

## 安装 ROS 并设置软件源（使用 RDK 官方镜像时）

::: info
使用百度网盘镜像的同学不需要进行此操作。
:::

首先，我们执行下方的一条命令将 PyPI 源替换为清华镜像源，然后再进行 ROS2 的安装，同时更换我们的系统软件包源。

```bash
pip config set global.index-url https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple
```

由于网络上的很多 ROS2 的安装教程过于繁琐，故我们使用由鱼香 ROS 提供的安装脚本来进行 ROS2 的安装，同时更换我们的系统软件包源。

请在你的车模终端中输入下方命令以执行一键安装脚本：

```bash
wget http://fishros.com/install -O fishros && . fishros
```

![示意图](/origincar/env/ros2-install/01-image17.webp)

如果它要求你输入 sudo 密码，请输入后执行。

![示意图](/origincar/quickstart/board-init/01-image60.webp)

选择 5 以更换系统源，之后，选择 **1：仅更换系统源**。

![示意图](/origincar/quickstart/board-init/02-image61.webp)

之后，我们选择 **根据测速结果手动选择源**：

![示意图](/origincar/env/ros2-install/04-image20.webp)

脚本会自动进行可用源的检测，当检测完成后，我们选择清华源（国内最为完整稳定的镜像源），为图中的第 2 个选项（<strong><https://mirrors.tuna.tsinghua.edu.cn/ubuntu></strong>）

![示意图](/origincar/quickstart/board-init/03-image62.webp)

选择后，脚本会自动更换镜像源，并更新 apt 索引。镜像源更换完成后，脚本会询问是否继续添加 ROS 源，我们选择 <strong>1：添加 ROS/ROS2 源，</strong> 脚本会继续添加 ROS 源密钥。

![示意图](/origincar/quickstart/board-init/04-image63.webp)

然后脚本会询问你选择哪一个 ROS 镜像源。为了索引的统一性，我们依然选择 **清华镜像源**（无需理会可能被封禁的提示）

![示意图](/origincar/env/ros2-install/06-image22.webp)

完成后，脚本会自动退出。

由于车模镜像为 Ubuntu Server 版本，缺乏完整 GUI 支持，我们需通过以下两条命令手动安装 ROS2 的必要组件：

```bash
pip3 install colcon-common-extensions
sudo apt install ros-humble-navigation2 ros-humble-nav2-bringup ros-humble-robot-localization ros-humble-teleop-twist-keyboard python3-ament-package ros-humble-ament-cmake ros-humble-cv-bridge ros-humble-joint-state-publisher ros-humble-imu-filter-madgwick ros-humble-image-transport -y
```

然后，我们执行下方的两条命令，将 TogetherROS 和 ROS 的 source 命令写入.bashrc 文件中：

```bash
echo -e "source /opt/ros/humble/setup.bash\nsource /opt/tros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

## 设置系统语言

我们将使用 RDK Software Configuration Tool 来完成这个操作，我们执行下方命令来打开配置工具：

```bash
sudo srpi-config
```

然后我们用方向键选中「5 Localisation Options」，按下回车进入：

![示意图](/origincar/quickstart/board-init/05-image64.webp)

然后选中「L1 Locale」，按下回车：

![示意图](/origincar/quickstart/board-init/06-image65.webp)

你应当能够看到下面的页面（大概率是英文），用鼠标滚轮下滑：

![示意图](/origincar/env/ubuntu-init/05-image7.webp)

找到「zh_CN.UTF-8 UTF-8」，按下空格选中：

![示意图](/origincar/env/ubuntu-init/06-image8.webp)

按下 Tab 键让光标跳转到&lt;确定&gt;后，按下回车，进入默认语言选择页面：

![示意图](/origincar/env/ubuntu-init/07-image9.webp)

选中 zh_CN.UTF-8，按下回车确定，当提示 Generation complete.后即完成语言配置。按下 ESC 退出配置工具即可。

## 存储空间扩容及更新 Miniboot

车模的镜像在上传前进行了压缩，所以我们需要对根目录进行扩容操作，我们打开使用 RDK Software Configuration Tool 来进行操作。打开后，我们用方向键选中「6 Advanced Options」，按下回车进入：

![示意图](/origincar/quickstart/board-init/07-image66.webp)

然后选中「A1 Expand Filesystem」，按下回车进行文件系统扩容：

![示意图](/origincar/quickstart/board-init/08-image67.webp)

当显示以下页面时，则代表根目录完成了扩容操作，我们按下回车确认：

![示意图](/origincar/quickstart/board-init/09-image68.webp)

确认后，我们再次用方向键选中「1 System Options」，按下回车进入：

![示意图](/origincar/quickstart/board-init/10-image69.webp)

然后选中「S7 Update Miniboot」，按下回车进行 Miniboot 更新：

![示意图](/origincar/quickstart/board-init/11-image70.webp)

接下来它会提示操作不可中止，我们用方向键选择「是」后，按下回车继续操作：

![示意图](/origincar/quickstart/board-init/12-image71.webp)

接下来它会提示操作需要联网，若你已经连接了无线网络，则用方向键选择「是」后，按下回车继续操作，否则请退出配置工具连接无线网络后重试：

![示意图](/origincar/quickstart/board-init/13-image72.webp)

若有提示「Continue update anyway? [y/N] (5s to respond):」，请在 5s 内输入 y 确定并回车，否则会造成更新失败。

完成更新后，使用 ESC 退出工具，然后输入下方命令重启，即完成 miniboot 更新：

```bash
sudo reboot now
```
