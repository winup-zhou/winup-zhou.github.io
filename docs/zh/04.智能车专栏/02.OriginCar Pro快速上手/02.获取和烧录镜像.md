# 获取和烧录镜像

::: info
百度网盘中的镜像版本可能较旧，我们建议基于 RDK X5 官方镜像进行烧录，官方镜像往往会更新并修复一些问题。<br>但 RDK 官方镜像中没有 OriginCar Pro 的功能包，我们需要 **后续自行上传**。如果你的 Linux 知识有限，保险起见请选择百度网盘镜像。
:::

车模生产后 SD 卡内默认没有烧录镜像，我们需要进行镜像的烧录。OriginCar Pro 的镜像在以下百度网盘链接中：[origincar_pro_sd_image_v1.0.0.rar_免费高速下载|百度网盘-分享无限制](https://pan.baidu.com/s/1rB9nHVzj_LDpAhPHqEUr4w?pwd=373x)

![示意图](/origincar/quickstart/flash-image/01-image33.webp)

::: warning
百度网盘非会员用户的文件下载速度会缓慢得令人难以接受，下载需要较长的时间。<br>我们建议事先借用会员用户的账号进行下载，然后采用其他方式进行再分发。
:::

如果你选择使用 RDK 官方的镜像，请移步此处进行下载：[Index of /downloads/os_images/rdk_x5/](https://archive.d-robotics.cc/downloads/os_images/rdk_x5/)，车模镜像应当选择 Ubuntu 的 Server 版本（无图形化页面），以减少不必要的硬件资源开销。截至本文编写时，RDK 官方镜像的最新版本为 2025 年 9 月 28 日发布的 3.3.3。

将镜像文件保存在合适位置后，我们还需要下载以下软件：

| [Rufus - 轻松创建 USB 启动盘](https://rufus.ie/zh/) | 镜像烧录软件，用于镜像的烧录，建议下载便携版 |
| --- | --- |

下载并安装完成后，我们拿出箱子内的蓝色的 USB 读卡器，将其插入电脑，并将一个容量≥16GB 的 SD 卡插入读卡器中，然后启动 Rufus 镜像烧录软件。

::: warning
为了防止误操作，请事先 <strong>拔出插在电脑上的其他所有 USB 存储设备！</strong><br>请仔细确认 SD 卡的设备号，以及 SD 卡中是否还有需要保存的数据。<br><strong>系统镜像烧录后，原有数据将全部丢失，该操作不可逆！</strong>
:::

确认 SD 卡设备号，选择要烧写的系统镜像：

![示意图](/origincar/quickstart/flash-image/02-image34.webp)

点击「开始」后，继续点击「确认」，开始烧写镜像：

![示意图](/origincar/quickstart/flash-image/03-image35.webp)

进度条会显示当前的烧写进度，烧写完成后，即可退出软件。

![示意图](/origincar/quickstart/flash-image/04-image36.webp)

退出软件后，请拔下 SD 卡，并将其插在车模 RDK X5 开发板的 SD 卡插槽位置。注意正反，不要使用蛮力。

::: warning
拔插 SD 卡前必须先断电！否则可能会造成开发板或 SD 卡烧毁。
:::
