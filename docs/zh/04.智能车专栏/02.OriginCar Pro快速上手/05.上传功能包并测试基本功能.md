# 上传功能包并测试基本功能的使用

完成上述初期配置之后，我们将功能包文件中的 dev_ws 文件夹上传到车模的/userdata/dev_ws 路径中。

功能包中附带的库文件/libion.so 请上传到/usr/hobot/lib 路径中。

::: info
功能包文件为附带的 X5 用功能包 (附带资料/X5 用.zip)。<br>请解压到合适位置之后，使用上文提及的任意连接方法将其上传到车模上要求的文件夹中。
:::

上传文件后，我们在车模的 SSH 终端中，切换到工作空间，输入下方的三条命令进行功能包的编译与安装：

```bash
cd /userdata/dev_ws/
sudo apt install libzbar-dev libzbar0 -y
colcon build --symlink-install
```

编译完成后，我们输入下方的两条命令，将功能包的安装信息写入.bashrc 中，以便车模启动后能够自动获取到功能包的安装文件路径：

```bash
echo "source /userdata/dev_ws/install/setup.bash " >> ~/.bashrc
source ~/.bashrc
```

之后，我们测试一下车模的基本功能。我们将会使用键盘控制节点来进行车模运动的简单控制。我们在当前终端中输入以下命令以启动与车模底盘相关联的功能包：

```bash
ros2 launch origincar_base origincar_bringup.launch.py
```

然后，我们打开一个新的 SSH 终端，连接到车模后，启动键盘控制节点：

```bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

我们按照屏幕提示的按键，使用键盘进行车模的控制。键盘节点会发布速度消息到/cmd_vel 话题，底盘节点订阅速度消息实现键盘控制，车模应当会跟随你的键盘指令进行移动。

如果车模可以进行运动，则代表车模的基本环境配置基本无误。否则，请检查你的环境配置是否正常，或者重新上传功能包。

::: info
如果车模没有运动，请检查 STM32 主控板上的 **电机使能拨扭开关** 是否已开启。开启时，车模的 OLED 显示屏应当显示 ROS：ON，这是车模能够进行运动的先决条件。
:::
