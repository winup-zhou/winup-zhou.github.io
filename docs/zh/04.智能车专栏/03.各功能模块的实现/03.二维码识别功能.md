# 二维码识别功能

该节点接收来自 USB 摄像头的/image 话题，节点从话题接收的每一帧使用 OpenCV 进行图像信息解码，并将图像转化为灰度图后使用 zbar 库（逐行扫描）进行二维码识别。若该帧存在有效二维码，则将二维码解码后的结果字符串发布到/sign 话题。

由于车模没有预装 zbar 库，我们需要使用 apt 命令来安装这个依赖库，然后输入下方的三条命令进行编译：

```bash
sudo apt install libzbar-dev libzbar0 -y
cd /userdata/dev_ws/
colcon build --packages-select qr_decoder
```

之后，可以使用下方命令来启动该节点：

```bash
ros2 run qr_decoder qr_decoder
```

::: info
若未开启摄像头节点，你需要手动开启，否则二维码识别节点将无法获得有效的图像数据：
:::

你可以使用二维码生成器，将生成的二维码放置到小车的单目摄像头前。若小车成功识别出了二维码，将会输出解码结果到终端：
