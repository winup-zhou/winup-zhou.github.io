# 图生文功能

## 原理说明

该节点接收来自上位机的/sign4return 话题和来自 USB 摄像头的/image 话题。USB 摄像头每发布新的一帧图像时，节点都将该帧图像存储在变量中。当上位机话题发布 data = 100 的信息时，节点取出最新一帧图像，使用 OpenCV 解码后将其上传到 TOS，并通过火山大模型的 API 调用图生文功能。获取到返回结果后，节点将结果字符串发布到/image_analysis_result 话题。

::: warning
该功能必须联网使用。
:::

## 火山大模型 API 申请

我们的图生文功能将会使用火山引擎提供的云端服务，主要有视觉大模型和对象存储两个主要的功能。我们事先访问 [火山引擎-你的 AI 云 (https:/www.volcengine.com/)](https://www.volcengine.com/) 注册一个账号。

然后，点击右上角图像旁的控制台，点击自定义快捷入口 - 添加入口，添加「火山方舟」和「对象存储」两个入口。这两个功能为我们后续主要使用的功能：

![示意图](/origincar/modules/image-to-text/01-image79.webp)

我们点击「火山方舟」，进入火山方舟管理控制台，然后在左侧的列表中，找到「API Key 管理」，点击进入，创建一个新的 API key，复制保存：

![示意图](/origincar/modules/image-to-text/02-image80.webp)

然后，我们点击「开通管理」，选择一个合适的图生文模型，点击开通（）：

![示意图](/origincar/modules/image-to-text/03-image81.webp)

点击左侧蓝字，进入模型简介，然后记住你的 Model ID：

![示意图](/origincar/modules/image-to-text/04-image82.webp)

完成后，我们进入 [访问控制-火山引擎](https://console.volcengine.com/iam/identitymanage/user)，在「用户管理」中新建一个子用户，并勾选「编程访问」，给予所有权限。创建完成后，我们进入这个子用户的「密钥」页面，创建一个新的密钥，并记住它的用户 ID，Access Key ID 和 Secret Access Key：

![示意图](/origincar/modules/image-to-text/05-image83.webp)

之后，我们回到控制台，点击「对象存储」，进入对象存储页面，然后点击左侧的「桶列表」，点击「创建桶」，我们需要为图生文节点创建一个存储桶来保存用于分析的图像，区域与桶策略的配置可以参考下图，名称请自行选择：

![示意图](/origincar/modules/image-to-text/06-image84.webp)

::: info
如果提示存储桶 **正在使用中**，请更换另外一个名称后重试。
:::

创建完成后，点击进入这个存储桶，进入「权限管理 &gt; 桶 ACLs」，点击「创建账号授权」，输入刚才创建的子用户的用户 ID，并给予读取和写入权限，确认保存：

![示意图](/origincar/modules/image-to-text/07-image85.webp)

至此，你已经完成了 API 申请的相关操作，请记住上文提及的 API Key，Model ID，桶名称，Access Key ID 和 Secret Access Key。

## 编译与启动节点

该节点需要使用下方的两条 pip 命令安装下列 Python 依赖库：

```bash
pip install tos
pip install -U volcengine-python-sdk[ark]
```

然后，我们回到工作空间，使用下方的两条命令进行编译：

```bash
cd /userdata/dev_ws/
colcon build --packages-select image_upload_analyzer
```

之后，可以使用下方命令来启动该节点：

```bash
ros2 run image_upload_analyzer image_upload_analyzer
```
