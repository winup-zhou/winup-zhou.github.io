# 基于视觉模型的运动控制

视觉模型部署完成后，我们将使用功能包中的巡线避障 demo 进行车模的运动控制。

该节点接收来自 DNN（模型分析）节点的信息。该信息为一个数组，其中，数组的每个元素包含 <strong>目标左上角点在图像中的坐标，识别框的长和宽，以及模型推测的目标类型（比如线或锥桶）</strong>。节点在每次接收到发布的信息后都先将识别结果进行分类处理，然后进行避障和巡线。

对于巡线，该节点会取画面中最靠下的线为目标，基于 **该线识别框中心点的横坐标** 与 **画面中心的横坐标** 差值进行比例控制。

对于避障，当识别结果中某一锥桶识别框的高度高于设定的像素值，将会触发避障/紧急避障。节点将会根据锥桶识别框中心点的横坐标，选择不同的避障方向（锥桶偏右向左避障，反之同理；锥桶识别框中心点的横坐标若较为接近画面中心的横坐标，则根据设定的优先方向进行躲避）。车模转向后，会直线向前行进一段距离。前行后，若发现有效线，则回到巡线状态；否则，将会向避障方向的反方向转向，进入丢线寻找状态，直到搜索到有效线。

该功能包的启动文件位于/userdata/dev_ws/src/origincar/origincar_competition/launch/start.launch.py，里面定义了很多避障巡线的参数，可根据车模的实际表现进行修改：

<img src="/origincar/modules/motion-control/01-image130.webp" alt="示意图" width="688" />

修改并编译完成后，将车模放置在场地的起点，然后按顺序开启底盘和运动控制节点，运动控制节点会自动启动摄像头、模型识别和二维码识别节点：

```bash
ros2 launch origincar_base origincar_bringup.launch.py
ros2 launch origincar_competition start.launch.py
```

启动后，车模应当会自行前往任务发布点去识别二维码，当读取到有效的二维码后车模会停止。

当完成在诊疗室内的操作回到诊疗室出口后，当节点接收到来自上位机/sign4return 话题的 data = 6 的消息后，车模会进入第二次巡线回到出发点。当车模至少有三个车轮压入出发点时，车模不会自动停车，使用 Ctrl+C 终止节点即可停车。

::: info
该节点仅作为算法的演示，你可以通过修改源代码增加和改进更多功能，如引入 PID 控制，自动停车、节点启动后不直接开始运动等。
:::
