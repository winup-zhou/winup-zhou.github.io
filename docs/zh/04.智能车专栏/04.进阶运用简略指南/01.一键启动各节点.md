# 一键启动各节点

前文所述的各节点独立启动方式在一定程度上是不方便的。我们可以通过创建一个仅包含 launch 文件的功能包，配置好 cmakelists.txt 或者 setup.py（取决于你的功能包类型）中安装 launch 文件的参数，将各节点合并到一个启动文件一起启动。

启动文件的示例可以见下（涉及使用 xml 启动文件的功能包，Python 启动文件的功能包和没有启动文件的功能包的情况）：

<img src="/origincar/advanced/one-click/01-image132.webp" alt="示意图" width="688" />

::: info
对于 cmakelists.txt，复制安装启动文件的参数如下：

```cmake
install(
  DIRECTORY launch
  DESTINATION share/${PROJECT_NAME}
)
```

而对于 setup.py，复制安装启动文件的参数如下：

```python
from glob import glob
# 需要导入上方模块用于定位启动文件位置
data_files=[
    # 此处省略了其他内容
    ('share/' + package_name, glob("launch/*.launch.py")),
],
```
:::

之后，使用命令启动这个功能包内的启动文件，就可以把所有的节点一起一键启动，在比赛时可以节省不少时间。
