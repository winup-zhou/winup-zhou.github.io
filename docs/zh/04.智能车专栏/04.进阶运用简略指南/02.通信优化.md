# 通信优化

在比赛场地会有各种原因的信号干扰，造成车模与上位机之间的通信不畅，在第二阶段遥操作时可能会导致避障不及时等问题导致罚时，所以我们需要进行一定的通信优化，我们摸索出了以下原则：

<strong>使用路由器桥接手机热点后进行连接，而不是直接连接手机热点。</strong> 手机热点的信号覆盖范围、稳定性和处理能力无法与路由器相提并论。路由器可以良好承载车模与上位机之间的通信数据量，并且抗干扰性能更好。

<strong>连接 WiFi 的 5GHz 频段，而不是 2.4GHz 频段。</strong>2.4GHz 频段的 WiFi 虽然穿墙能力更好，但是其网络速率受限，难以承载车模与上位机之间的通信。

<strong>车模使用外置天线或外置 USB 无线网卡。</strong> 外置天线或外置 USB 无线网卡可以扩大车模信号的接收范围，从而有效提高信号连接的质量和稳定性。
