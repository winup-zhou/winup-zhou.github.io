# 开发板性能提升

你可以通过对开发板超频来提升开发板的性能，但是 <strong>必须做好散热措施（如加装散热风扇，加装更大的散热片）</strong>，否则可能会导致开发板烧毁。

有关超频和频率管理的详细内容请参阅：2.4 Thermal 和 CPU 频率管理 | RDK DOC (https://developer.d-robotics.cc/rdk_doc/System_configuration/frequency_management#cpu%E9%A2%91%E7%8E%87%E7%AE%A1%E7%90%86-1)。
