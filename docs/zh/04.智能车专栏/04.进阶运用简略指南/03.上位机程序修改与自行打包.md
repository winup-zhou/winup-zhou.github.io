# 上位机程序修改与自行打包

上文所述上位机启动文件中的 src 文件夹是上位机启动程序的源代码，dist 为该源代码程序打包后的二进制可执行文件。我们可以使用上文提及的 conda，创建独立的虚拟开发环境。

创建完独立的开发环境后，你可以选用 VSCode 或者 Pycharm 等支持虚拟环境的 IDE 进行开发。在进行开发之前，你需要先切换到刚创建的虚拟环境 <strong>（终端和 IDE 的解释器均需要切换）</strong>，然后切换到你的「数字环境及启动文件」文件夹，在虚拟环境中的终端执行以下命令来配置上位机程序的依赖：

```bash
pip install -r src/requirements.txt
```

你可以根据需要进行按键监听，话题发送等功能代码的修改，修改完成后，输入下列指令进行打包生成二进制文件：

```bash
pyinstaller src/bridge_client.spec
```

dist 文件夹中会生成打包后的上位机启动程序的二进制可执行文件，该文件可以直接双击启动，免去了输入指令的麻烦，只需修改 config.yaml 内的配置即可。
