# 深度相机的使用

要使用车模上的深度相机，你需要进入/userdata/dev_ws/src/origincar/3rdparty/aurora930 目录，然后使用下方的第二条命令来安装厂商提供的深度相机驱动：

```bash
cd /userdata/dev_ws/src/origincar/3rdparty/aurora930
dpkg -i ros-humble-deptrum-ros-driver-aurora930_0.2.4-0jammy_arm64.deb
```

厂商在该文件夹内的 usage_aurora930.md 文档中描述了部分的使用方法，有关操作手册，DataSheet，SDK 等资料的获取请参照附带的 Aurora930 深度相机资料 (附带资料\Aurora930 深度相机资料)文件夹内的相关文档。

如果你想让深度相机的坐标系与车模其他设备的坐标系进行结合，你需要修改 origincar_description 功能包中有关机器人结构描述的文件来进行坐标系变换。在此不过多赘述具体技术细节。
