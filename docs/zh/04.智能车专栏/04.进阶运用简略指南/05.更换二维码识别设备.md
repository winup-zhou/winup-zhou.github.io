# 更换二维码识别设备

如上文所述，二维码识别节点订阅的图像来自/image 话题，类型为 sensor_msgs/CompressedImage，该图像来自车模前方的单目摄像头。

我们可以通过修改节点代码的方式，让该节点订阅深度相机发布的彩色图像数据，以加快识别速度，同时深度相机的安装位置可以让车模在更远的距离识别二维码。

深度相机发布的 RGB 图像信息话题为/aurora/rgb/image_raw，类型为 sensor_msgs/Image。该消息类型不能被 OpenCV 直接解码，你需要同时引入 CV Bridge 来对图像进行转换处理。在此不过多赘述技术细节。
