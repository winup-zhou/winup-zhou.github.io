# GRS Micro Cabmatic 信号系统概述

::: info
本文根据《上海地铁一号线 ATC 信号系统》培训资料整理。该线使用的 ATC 系统为 **GRS Micro Cabmatic**，由卡斯柯信号有限公司（CASCO）提供。
:::

## 系统简介

上海地铁一号线使用的 ATC 信号系统由卡斯柯信号有限公司（CASCO）提供。ATC（Automatic Train Control，列车自动控制）系统由两大部分构成：

- **轨旁 ATC 系统**：ATP（列车自动防护）、ATO（列车自动驾驶）、VPI（安全型计算机联锁）、MMI（人机接口）、SDM（系统维护台）、ATS（列车自动监控）
- **车载 ATC 系统**：车载 ATP、车载 ATO、车载 ATS（含 TWC 车地通信），以及配套的车载机架、板卡与车下传感器

轨旁设备负责生成列车检测信号与速度码并向钢轨发送，车载设备通过接收线圈获取这些信息，据此完成超速防护、自动驾驶与车站程序停车。

## 车站系统构成

![一号线车站系统图](/signals/img/micro-cabmatic/station-system.webp)

车站系统由室内设备与室外设备两部分组成。

### 室内设备

| 设备 | 说明 |
| --- | --- |
| ATP 架 | 轨旁列车自动防护设备，产生列车检测信号、速度码与开门码 |
| ATO 架 | 轨旁列车自动驾驶设备，处理标志线圈与对位天线信息，实现程序停车与屏蔽门控制 |
| 接口架 | ATP/ATO 架与联锁、控制台之间的接口设备 |
| 6502 架（VPI） | 车站联锁设备，6502 电气集中或 VPI 安全型计算机联锁 |
| 控制台（MMI） | 值班员操作终端，显示站场并办理进路 |
| DT、MODEM | 数据传输设备，经通信通道与 OCC 中央 ATS 连接 |

### 室外设备

沿线路布置的设备包括：

- **阻抗联接器（BOND）**：发送/接收列车检测信号、速度码，并承担 TWC 车地通信的耦合
- **终端接收器（TR）**：仅接收列车检测信号
- **无源标志线圈**：距停车点 350m、150m、25m 处设置，用于启动与修正车站停车曲线
- **8m 标志线圈**：距停车点 8m 处设置，用于调整列车停车减速率
- **AA 对位天线**：站台侧设置，与车载对位天线配合实现精确对位停车，并传递车长信息以控制屏蔽门
- **4 英尺环线、长环线、AC 耦合单元、调谐单元**：用于道岔区段发送列车检测信号与速度码

## 子系统一览

| 子系统 | 全称 | 主要作用 |
| --- | --- | --- |
| ATP | Automatic Train Protection | 保证后续列车根据与前行列车的距离及进路条件自动调整运行速度，确保安全运行间隔 |
| ATO | Automatic Train Operation | 提供列车运行速度的自动调整控制，实现程序停车（台阶式制动） |
| VPI | Vital Processor Interlocking | 故障-安全的车站联锁信号控制系统 |
| MMI | Man Machine Interface | 值班员操作与站场显示 |
| SDM | System Diagnostic Maintenance | 系统维护及接口设备监测 |
| ATS | Automatic Train Supervision | 监督和控制列车运行，自动进路设置、时刻表管理与运行调整 |
| 车载 ATP | — | 机车信号接收、速度检测、超速防护、制动保证、车门控制、零速检测、无意移动防护、退溜防护 |
| 车载 ATO | — | 速度调整、牵引/制动控制、程序停车、惰行模式 |
| 车载 ATS | — | 通过 TWC 与轨旁交换数据，实现调度、停车、排列进路与监控 |
