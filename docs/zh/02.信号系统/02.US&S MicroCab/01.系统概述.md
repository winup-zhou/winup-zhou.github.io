# US&S MicroCab 信号系统概述

::: info
本文根据《上海地铁二号线车载基础知识培训》资料、《AF-902/AF-904 Generation II 音频轨道电路现场维护手册》（SM1F2.0001）与《TWC 车地通信系统轨旁设备操作与维护手册》（SM8054）整理。二号线使用的 ATC 系统为 **US&S MicroCab II**，由联合道岔与信号公司（Union Switch & Signal，US&S，后并入日立轨道 STS）提供。
:::

## 系统简介

上海地铁二号线的 ATC（Automatic Train Control，列车自动控制）系统由三部分构成：

- **车载 ATC 系统**：MicroCab II 机架（安装 ATP 与 ATO 子系统）、ADU 与辅助 ADU、TWC 天线、ATP 接收线圈、2 个独立 EOSS 速度传感器、MR 无线模块及其与车辆的接口
- **轨旁 ATC 系统**：AF-902/AF-904 音频轨道电路（列车检测与机车信号发送）、TWC 轨旁设备（TWCW）、MicroLok II 联锁与轨道逻辑、方向继电器及钢轨耦合设备
- **中央 ATC 系统**：控制进路与时刻表，使调度员在中央控制设备上监视并控制车辆与轨旁设备

轨旁设备通过钢轨向列车传输经 FSK 调制的数字机车信号，车载设备用接收线圈获取并解码，据此完成超速防护、自动驾驶与车站程序停车；车地之间的非安全数据（车次号、目的地 ID、停车命令等）则通过 TWC 环线以半双工方式交换。

## 车载系统构成

| 部分 | 设备 | 说明 |
| --- | --- | --- |
| 机架 | MicroCab II 机架 | 安装 ATP、ATO 子系统，含主 ATP、辅助 ATP、ATO、I/O 机笼与电源抽屉 |
| 显示 | ADU、辅助 ADU | 状态显示单元，显示速度、机车信号、限速与故障信息；辅助 ADU 输入 DID 与司机 ID |
| 测速 | EOSS A、EOSS B | 2 个独立安装的光电速度传感器，电源分别供给 |
| 接收 | ATP 接收线圈、TWC 天线 | 分别接收钢轨机车信号与 TWC 环线数据 |
| 无线 | MR 模块 | MR 主机、车载终端服务器与天线，用于与轨旁建立 MR-AP 通道 |
| 接口 | J1～J6 航插 | ATC 与车辆列车线、逻辑及串行接口的内部连接条件 |

机架内部划分为主 ATP 机笼、辅助 ATP 机笼、ATO 机笼、I/O 机笼、安全及电器部分与供电抽屉（A84、A85）；机笼母板编号为 A23（主 ATP）、A46（辅助 ATP）、A69（ATO），另有 A82/A83 阻抗集合。

## 运行模式

| 模式 | 含义 | 说明 |
| --- | --- | --- |
| ATO 模式 | 自动模式 | ATP 监督下由 ATO 完成速度调整与程序停车 |
| ATP 模式 | 手动模式 | 由司机驾驶，ATP 只提供超速防护 |
| Close In 模式 | 慢速前行模式 | 以受限速度接近目标点 |
| BYPASS 模式 | 切除模式 | ATP 不提供防护，ATP/ATO 电气隔离 |

::: warning
旁路模式下 ATP 不提供防护。此时仍会通过独立的 EOSS 速度输入在 ADU 上显示列车速度，仅供司机参考。
:::

## 子系统一览

| 子系统 | 全称 | 主要作用 |
| --- | --- | --- |
| ATP | Automatic Train Protection | 冗余配置的安全子系统，承担机车信号接收解码、速度与位置判定、超速防护、制动与牵引控制、门控制、方向控制、PVID 与意外脱钩检测 |
| ATO | Automatic Train Operation | 非安全子系统，始终在 ATP 监督下运行，完成速度调节、程序停车、列车识别与调停、运行监督与事件记录 |
| TWC | Train to Wayside Communications | 车地通信，经环线以半双工 FSK 方式在车载与轨旁之间交换非安全数据，并支持连续发送模式（CTM）实现程序停车 |
| AF-902/AF-904 | Audio Frequency Track Circuit | 轨旁音频轨道电路，完成列车检测并向列车发送数字机车信号 |
| MicroLok II | — | 轨旁安全逻辑处理器，完成轨道逻辑与联锁逻辑，并与轨道电路交换轨道电路 ID、限速、目标速度等数据 |

## 与一号线的差异

| 项目 | 一号线（GRS Micro Cabmatic） | 二号线（US&S MicroCab） |
| --- | --- | --- |
| 轨道电路 | GRS 音频轨道电路，载频 2625～4275 Hz | AF-902/AF-904 音频轨道电路，载频 9.5～16.5 kHz |
| 列车检测信息 | 速度码、开门码 | 轨道电路 ID、线路速度、目标速度、目标距离、方向、下一载频、连挂信息 |
| 信息调制 | 载频 + 调制频（2/3 Hz） | FSK 移频键控数字报文 |
| 车地通信 | 经阻抗联接器（BOND）的 9650 Hz 通道 | TWC 环线，54/64 kHz FSK，半双工 |
| 精确停车 | 标志线圈（350/150/25/8 m）与对位天线 | TWC 环线交叉点与 CTM 模式，延伸段增设棒线（berth loop） |
| 屏蔽门控制 | 经 AA 对位天线与 8M 标志线圈交换对位与车长信息，由轨旁 6 车/8 车继电器控制相应车长的屏蔽门开闭 | 既有线：轨旁经 TWC 环线下发 berth 信息与门使能信号；延伸段：由车载产生 berth 信息与门使能信号，经 MR-AP 通道与轨旁交互开关门命令 |
