# US&S MicroCab 车载设备

二号线的车载 ATC 采用 US&S MicroCab II 系统，每列车两端各设一套。车载 ATC 由 ATP、ATO、TWC 三个子系统组成，其中所有涉及安全的功能全部归入 ATP 子系统，ATO 为非安全子系统，TWC 负责车地之间的非安全数据交换。

## 车载系统构成

- **1 个 MicroCab II 机架**：安装 ATP 与 ATO 子系统
- **显示设备**：ADU、辅助 ADU、1 个 ADU 电源
- **天线与传感器**：TWC 天线、2 个 ATP 接收线圈、2 个独立 EOSS（A/B）
- **无线模块**：MR 模块（MR 主机、车载终端服务器、MR 天线）
- **接口**：ATC 与车辆列车线、逻辑与串行接口的内部连接条件

机架内部划分为主 ATP 机笼、辅助 ATP 机笼、ATO 机笼、I/O 机笼、安全及电器部分与供电抽屉（A84、A85）。机笼母板编号为 A23（主 ATP）、A46（辅助 ATP）、A69（ATO），另有 A82/A83 阻抗集合；A84/A85 抽屉电源同时为辅助 ADU 提供 12 V 电源。

与机架连接的外部模块还包括接线盒（Junking box）等。

### 机笼构成

车载机架自上而下分为主 ATP 机笼、辅助 ATP 机笼、ATO 机笼、I/O 机笼、安全及电器部分与供电抽屉，各类板卡均插接在背板母板上。各机笼内板卡的槽位与功能见下文[机笼与板卡布局](#机笼与板卡布局)。

### 外部部件

**ADU 与辅助 ADU**：ADU（状态显示单元）位于司机台，显示速度、机车信号、限速与故障信息，司机通过 ADU 完成发车、模式选择等操作。ADU 电源是一个独立的组合，将 110 V 转换为 ADU 及 EOSS B 一个通道所需的电源；**ADU 电源必须使用独立于 ATC 机柜的电池电源**，以便在机柜断电或故障时，ADU 仍可作为速度计使用。辅助 ADU 用于输入司机 ID 与目的地 ID（DID），面板上设有拨码开关与三位数码轮，输入后按 ENTER 键确认。

<img src="/signals/img/microcab/aux-adu.webp" alt="辅助 ADU（司机 ID 与目的地 ID 输入）" width="688" />

**机车信号接收线圈**：安装在车下、位于钢轨上方，接收轨旁经钢轨发送的 FSK 机车信号，送入机架内的 FSK 接收板与 FSK CPU 板解码。每端司机室各设 2 个接收线圈。

<img src="/signals/img/microcab/pickup-coil.webp" alt="车下的机车信号接收线圈" width="688" />

**TWC 天线**：安装在车下，与轨旁铺设的 TWC 环线耦合，完成车地之间的半双工数据交换（地→车：车次号、DID、CTM 等信息；车→地：车长、DID、车次号等状态数据），并通过 RX/TX 板与 ATO 机笼相连。

<img src="/signals/img/microcab/twc-antenna.webp" alt="TWC 天线" width="450" />

接收线圈与天线均经接线盒（Junking box）转接后进入机架；MR 模块（MR 主机、车载终端服务器、MR 天线）见下文「MR 与屏蔽门（PSD）」一节。

## ATP 子系统

### 冗余结构

ATP 子系统为冗余配置，具有故障自动切换能力：

- 由 **Main-ATP** 与 **AUX-ATP** 组成，主、备 ATP 单元采用并行连接，所有开关、控制、电源和外部通信接口全部提供冗余配置
- ATP 接收线圈、ADU 与所有 EOSS 都并行连接到每一个 ATP 单元；机架上的每个 ATP 单元均单独供电，两个 ATP 单元全部处于工作状态
- 若主 ATP 单元的输出被励磁接通，备用 ATP 单元的输出即被失磁切断
- 主 ATP 单元故障时，**只有当列车完全停稳后**，备用 ATP 单元才会自动接管相应工作
- 列车两端的 ATP 必须互锁：若列车另一端的 ATP 系统已被激活，本端 ATP 系统的开关输入将被切断，从而防止两套 ATC 设备同时工作

### ATP 的主要功能

- 机车信号接收及解码
- 车辆速度及位置的判定
- 安全超速保护
- 安全制动及牵引控制
- 站台停车
- 安全的车门控制
- 列车运行方向和运行方向的控制
- ATP 运行模式选择（Main / Aux）
- ATC 操作接口（ADU 接口要求）
- PVID（永久列车 ID）
- 意外脱钩检测（列车完整性检测）

### 机车信号的接收与解码

机车信号的"载体"是轨道电路：轨道电路为轨旁提供列车当前位置检测，并向列车提供行车控制命令。相邻轨道电路之间的电气绝缘节（S-BOND）是判定列车位置的参考点，轨道电路信号的门限电平则作为判定列车进入下一轨道电路的依据。

- **处理方式**：经过 FSK（移频键控）调制的数字形式安全信息通过轨道电路传送到列车，再由车载 ATP 子系统解码
- **频率**：8 个载频，从 9.5 kHz 到 16.5 kHz，步进 1 kHz
- **处理过程**：车载 ATP 系统通过三个数字滤波器中的一个得到相应的载频，第二个数字滤波器得到下一段轨道电路的载频，第三个用于测试频率
- **包含信息**：每个信息中包含速度命令（speed command）、轨道电路 ID（track ID）、下一段轨道电路的载频与开门命令（door control command）
- **接收方式**：ATP 通过接收线圈接收来自轨旁的安全信息

### 机车信号丢失（掉码）

ATP 在把解码数据作为新的有效机车信号数据之前，必须接收到**两个连续且相同**的新信息。只要采集的信息真实有效且连续被接收，机车信号就会被连续送入 ATP 处理。

- 若序列中的一个信息无效（循环冗余校验失败或内容不一致），则保留最后解码的信息，直到 2.75 s 计时器到时，或直到在当前载频（或解码得到的下一轨道电路载频）上重新取得有效数据
- 若安全计时器到时，则报告"机车信号丢失"消息，此时所有零速信息将被发送给 ATP 处理器，ATP 的反应是**实施停车**
- 列车停稳后，等待同样载频条件下丢失的信号，同时也等待最后一个有效机车信号数据中指示的下一个载频

### 速度检测与超速防护

ATP 子系统使用两个 EOSS（光电速度传感器）来安全地确定车速，使用两个的目的是相互检测、校验与核对，降低打滑、溜车等共模故障的可能性。

- ATP 使用 EOSS A 的一个输出通道与 EOSS B 的一个输出通道进行比较，并将速度信息传至两个独立计数器以判定列车的实际速度
- 计算方式：ATP 利用轮径信息将采集到的脉冲信息转化为线性长度，计算单位时间的脉冲速度即得到车辆速度
- 单个 EOSS 信号丢失时判定为打滑，将触发 IEB

超速防护方面：列车超出限速时施加 **全常用制动**调整车速；如持续超速则施加 **紧急制动**。超速限速为限速值加 2.5 km/h，速度采样的周期为 250 ms。

### 位置判定

列车位置采用"轨道电路 + track table"的顺序占用方式判定：

- ATP 从接收到的轨旁机车信号中识别被占用信息、轨道电路的 track ID 与方向控制数据
- 系统检测 track ID 的次序与运行方向是否匹配，从而判定列车当前位置
- 相邻轨道电路的电气绝缘节（S-Bond）是位置判定的参考点，也是列车从一段轨道电路进入另一段的分界点
- 运行位置与运行方向是列车安全追踪间隔、限速防护、站台门控等功能的重要依据

### EOSS 光电速度传感器

EOSS 用来确定列车运行的相关参数：

- 列车速度
- 列车运行方向
- 走行距离
- 空转 / 打滑
- 轮径磨损
- 后溜及爬行
- 停车

## ATO 子系统

ATO 子系统完成非安全的列车自动运行与监控功能，在列车运行过程中执行规定功能并与 ATP 交换数据。由于 ATO 始终在 ATP 的监督下运行，ATO 子系统本身并没有安全相关的要求。ATO 模式建立时，ATP 与 ATO 之间交换模式选择信息并激活相应命令，ATP 始终承担监督防护与数据交换的职责。

ATO 的主要功能包括：

- 速度调节
- 程序停车
- 列车的识别和调停
- ADU 辅助盘接口要求
- 运行监督
- 事件记录
- 车地通信

ATO 直接涉及的模块有 ADU、辅助 ADU、TWC、DTI 等。

### 速度确定与运行级别

ATO 通过统计缓存在每个 ATP 中的 EOSS B 输出脉冲数，估算列车运行参数：实际速度、空转打滑、走行距离（distance-to-go）、后溜、爬行与零速（停止）等信息。计算方式与 ATP 类似——已知轮径值，利用脉冲数换算距离，再由单位时间的脉冲数得到速度。

列车通过 TWC 接收由中央 ATC 制定的**运行级别**，级别信息包括速度限制、加速/减速限制命令与程序减速，由中央 ATC 的行车调整算法生成。

| 等级 | 限速 | 加速命令 | 程序减速 |
| --- | --- | --- | --- |
| 1 | 最大 | 1.0 m/s² | 1 |
| 2 | 90%（对 ATO 速度曲线） | 1.0 m/s² | 1 |
| 3 | 75%（对 ATO 速度曲线） | 1.0 m/s² | 1 |
| 4 | 50%（对 ATO 速度曲线） | 0.75 m/s² | 5 |
| 5 | 60 km/h | 0.75 m/s² | 5 |
| 6 | 40 km/h | 1.0 m/s² | 1 |

### 定位

与 ATP 类似，ATC 系统利用轨道电路得知当前占用的轨道电路 ID 与走行方向；ATO 进一步利用轨道电路闭塞分区的中断信号、TWC 的交叉信号、列车方向与轨道电路 ID 来确定列车的位置与走行方向。闭塞分区中断信号由 ATP CPU 以脉冲方式送给 ATO，表明列车已经越过该闭塞分区。

### 程序停车

程序停车（站台精确停车）是 ATO 的主要功能之一，由车载、轨旁与 OCC 协同完成。两种线路形式**都依靠检测 TWC 环线交叉点**来确认是否停准：

- **既有线**：列车进站前（第三接近区段）检测到预设信标后，以此为程序停站的起点，ATO CPU 根据列车速度、停车点距离与坡度等信息预设制动率并建立停车曲线；列车进站时 TWC 模式与 CTM 模式同时建立，通过检测 TWC 环线交叉点完成精确停车
- **延伸段**：过程相似，但增加了两个棒线（berth loop），窗口更小，站台两端各设一个，用于进一步校核列车位置，停车更精准，以适应屏蔽门（PSD）

跳停（skip-stop）由列车在两站之间的区间执行，通过 DID=055 或根据特殊需要、时刻表调整或功能测试触发。

<img src="/signals/img/microcab/twc-loop.webp" alt="TWC 环线布置示意" width="688" />

### 屏蔽门控制与发车保障

两种线路形式都通过 TWC 环线交叉点检测完成精确停车，但屏蔽门（PSD）的控制路径不同：

| 环节 | 既有线 | 延伸段 |
| --- | --- | --- |
| 门控信息来源 | 列车停准后，由**轨旁**经 TWC 环线向列车发送 berth 信息与门使能信号，告知列车是否停准、是否具备开关门条件 | 列车停准后，由**列车**产生 berth 信息与门使能信号，经 MR-AP 通道送到轨旁；轨旁收到后送出 PSD 开门命令，随后进行开门作业 |
| 发车保障 | 车门关闭后，列车将关门信息经 TWC 环线告知轨旁，即具备发车条件 | 车门关闭后，列车检测 PSD 的关门状态，再将车门关门信息与 PSD 关门信息**分别**经 MR-AP 通道送到轨旁，即具备发车条件 |

::: warning MR-AP 通信中断时的处理
延伸段若 MR-AP 通信中断，可手动切换门控一次并恢复：由车上模拟一个"PSD 已关好"的信息送到轨旁，此后列车才能收到机车信号，ATO 才能发车。
:::

### 轨旁侧的配合

列车进站检测到信标，并在窗口范围内检测到第一个环线交叉点后，机车通过交叉环线时轨旁检测到电流变化，从而计算列车走行距离。轨旁接收 OCC 指令后启动 CTM 模式，直到轨道电路检测到列车已精准停车，CTM 模式取消。

列车进站时 TWC 模式与 CTM 模式同时建立，ATO CPU 上相应的灯同时亮起；进站列车**只收不发**，停站后**只发不收**。

### DTI 发车指示器

DTI 设在站台，用于显示发车倒计时：

- 前一列车出发后至下一列车到达车站前，DTI 处于熄灭状态
- 下一列车到达车站停稳后，接到 MLK 发出的继电器触发信号，从规定的停站时间（可由拨码开关设置）开始以秒为单位递减倒计数
- 若倒计时显示"00"时仍未收到发车命令，则以秒为单位正计时显示晚点时间，达到最大值"99"时闪烁显示

以上功能的成立条件是无线通信正常，且列车门与屏蔽门正常开启。

## TWC 子系统（车载部分）

TWC 系统由车载部分（TWCC）与轨旁部分（TWCW）组成，实现车载设备与各类轨旁设备之间的非安全通信：

- **上行通信**：CTC 信息 → TWCW → TWCC → 车载控制设备
- **下行通信**：机车信息 → TWCC → TWCW → CTC

要确保车载设备精确停车，需要在 OCC 与列车之间建立数据链路，涉及三个部分：TWC PC（车地通信系统 PC 控制器）、TWC-C（车载部分）与 TWC-W（地面部分）。

<img src="/signals/img/microcab/twc-interfaces.webp" alt="TWC 通信接口" width="688" />

::: details TWC 系统要点
1. TWC 实现与 ATO 的非安全通信
2. 环线铺设在站台区域、车辆段与正线转轨处
3. 通信模式为双向的半双工模式，存在主从关系——车为主、地为辅
4. 车载通过 TWC 天线收发信息；轨旁通过 TWC 环线收发信息
5. 信息传输：地→车方向完成非安全控车功能，如车次号、DID、CTM 等信息；车→地方向完成状态数据传输，如车长、DID、车次号等
:::

## 主要板卡说明

本节对机架内主要板卡的构成与作用作补充说明，板卡所在机笼与槽位见上文[机笼与板卡布局](#机笼与板卡布局)。

### ATP 机笼单盘

**电源滤波板**：电池滤波板组合对主（和辅助）电池输入进行滤波和二极管或运算，输出主用（和辅用）5 V/30 V 电源及 ATP 逻辑继电器电源，并为 ATO 提供 ±12 V 电源、ATO 5 V/30 V 及 ATO 逻辑继电器供电。其四路输出分别为：

::: details 电源滤波板输出
| 电路 | 用途 |
| --- | --- |
| 1 | ATP 机笼的 5 V / 30 V 输入 |
| 2 | ATO 机笼的 5 V / 30 V 输入 |
| 3 | ATP 机笼的 ±5 V / 30 V 输入 |
| 4 | A：用于 Pro-enable 与 Door-enable 的主/备 VCOR（K1/K2）<br>B：用于主/备非安全继电器板组合，表示 I/O 机笼（A73/A7A 槽位）PCB 状态，以及 ATO 非安全继电器板组合，为 I/O 机笼（A78 槽位）提供牵引/惰行信号<br>C：为 I/O 机笼 A84、A85 的 ADU 辅助盘提供 ATO 12 V 电源，用于 I/O 机笼（A70 槽位）的安全继电器板组合 |
:::

**条件电源板**：为智能安全输出板提供直流电源。只有在 ATP 运行于安全模式时才会产生该电源；故障情况下将切断智能安全输出板的直流电源，使所有输出变为逻辑"0"状态——当列车正在 ATC 模式下运行时，这将导致紧急制动，从而让列车停下来。

**非安全输出板**：提供状态与故障输出，各输出定义如下。

::: details 非安全输出板输出定义
| 输出 | 定义 |
| --- | --- |
| OUT 0 | MASTER |
| OUT 1 | ERD |
| OUT 2 | ELD |
| OUT 3 | FSBR |
| OUT 4 | Serious Fault |
| OUT 5 | Medium Fault |
| OUT 6 | Minor Fault |
| OUT 7 | EOSS A 的电源输出（ATP 给 EOSS A 供电时该灯点亮） |
:::

**智能安全输出板**：为关键切换继电器（VCOR）提供励磁。断开 VCOR 的接点即切断安全继电器的电源，从而使列车施加紧急制动。指示灯含义：3 号 WDOG 闪烁表明 CPU 在运行；6 号 ERROR 灯亮表示板子处于错误状态；7 号（OUT 0）为 EBR / VCOR——采取紧急制动并切断牵引时该灯熄灭。

**安全输入板（A11）与安全输入板（A14）**：

::: details 安全输入板输入定义
| A11 | 定义 | A14 | 定义 |
| --- | --- | --- | --- |
| IN 0 | AUTO | IN 0 | ABR |
| IN 1 | ON MODE—ATP | IN 1 | RTDC |
| IN 2 | CAB | IN 2 | LTDC |
| IN 3 | ND | IN 3 | ADC |
| IN 4 | FWD | IN 4 | TUC |
| IN 5 | REV | IN 5 | NAB |
| IN 6 | 6-CAR | IN 6 | NDEB |
| IN 7 | 8-CAR | IN 7 | NFBF |
| IN 13 | master check | IN 8 | SBA |
| IN 14 | ERD check | IN 9 | PEC |
| IN 15 | LRD check | — | — |
:::

**转速接口板（Tach）**：为 ATP 子系统使用的两个速度传感器提供接口。该板与两个装在轮轴上的三通道光电速度传感器（EOSS A、EOSS B）相连，对脉冲进行处理，ATP 据此判断速度、距离、位置与运行方向。转速接口板还将 EOSS B 三个通道的脉冲相加后送给 ATO 子系统，ATO 利用该数据判断列车速度与行驶距离、计算轮径磨损、判定零速度（独立于 ATP）并检查任何超常的速度变化。

**FSK 接收板（FSK receiver）**：载频 9.5～16.5 kHz，Δf = 1 kHz。三个通道分别调谐：CH1 接收当前机车频率，CH2 接收下一区段的机车频率，CH3 接收测试频率。

**FSK CPU 板**：控制 FSK 接收板，对所接收的数据进行解码，并与 ATP CPU 板（应用处理器）通信。从轨道电路接收的数据包括轨道电路 ID、线路速度（最大允许速度）、目标速度、目标距离、方向和下一载频。**当丢失机车信号时，该板只向应用程序处理器发送数据"0"，导致列车施加全常用制动停车。**

**ATP CPU 板**：采用 68332 微处理器，实现车载 ATC 的安全逻辑与应用逻辑，并为输入/输出板提供软件接口。它接收安全输入，将安全输出送给智能安全输出板，同时控制两个 ATP 系统之间以及 ATP 与 ATO、ADU、FSK、PTU 之间的串行 I/O 口。


::: details ATP CPU 板指示灯
| 灯号 | 含义 |
| --- | --- |
| 3—A | Frequency Drop（频率下降） |
| 4—B | Frequency Rise（频率上升） |
| 5—C | Good Bond Crossing（正常通过连接线） |
| 6、7—D / E | 未使用 |
| 8 | ON LINE |
| 9 | VPP ON |
| 11—1 | ATP – ATP |
| 12—2 | ATP – ATO |
| 13—3 | ADU |
| 14—4 | PTU |
| 15—5 | FSK |
| 16—6 | MR |
:::

### ATO 机笼单盘

ATO 机笼内除电源板、自定义 I/O 板、屏蔽板、接收/发送组合板（经 TWC 天线收发数据）、P 线驱动板、非安全输出板、安全输入板与 EEPROM/备用电池外，核心为 68332 CPU 及子板（ATO CPU），实现速度调节与车站停车功能并支持 ATC 通信。P 线驱动板对列车用于控制牵引或制动大小的模拟信号作出响应（测试电压：control 2.0～2.8 V，feedback 0.1～1 V）。

::: details ATO CPU 板指示灯
| 灯号 | 含义 |
| --- | --- |
| 3—A | ATO – Main ATP（与主用 ATP 串行连接有效） |
| 4—B | ATO – Auxiliary ATP（与辅助 ATP 串行连接有效） |
| 5—C | ATO – TWC（ATO 与 TWC 连接有效） |
| 6—D | CTM 模式（CTM 模式建立） |
| 8 | ON LINE（板子通电时灯亮） |
| 9 | VPP ON（程序被载入时灯亮） |
:::

## MR 与屏蔽门（PSD）

MR（mobile radio）基于屏蔽门的考虑，利用无线通信技术，通过建立 MR-AP 通道接收和发送车载、轨旁以及屏蔽门动作的相关信息，从而实现对屏蔽门的安全操作。

| 位置 | 设备 |
| --- | --- |
| 车载 | MR 主机、车载终端服务器（terminal server）、天线 |
| 轨旁 | 轨旁终端服务器、AP、天线、交换机等 |

车载 MR 与车辆、ATC 之间的接口经 J6 连接。

<img src="/signals/img/microcab/mr-interface.webp" alt="MR 设备接口" width="688" />

屏蔽门的作用一方面是保证乘客安全，防止乘客跌落轨道或物品掉下轨道；另一方面可减少站台区与轨行区之间的冷热气流交换，降低环控系统能耗。

## 发车条件

**ATO 发车条件**：

- 与 ATP 的有效通信（例如无连接故障）
- 有效的目的 ID（包括 998，从 TWC 接收或人工输入）
- 有效的轨道电路 ID（从 ATP 获得）
- 非零速度设定（从 ATP 获得）
- 有效的行车方向（从 ATP 获得）
- 有效的车轮尺寸
- 无 ATP 可释放和不可释放的扣车被激活
- 来自 ATP 的列车"释放"信号（由 ATP 依据各种安全控制决定，按压 ADU 发车按钮）
- 在出发测试过程中未检测到错误
- 车地通信已建立
- 车门关闭

**ATP 发车条件**：进路信息正确，机车信号正常，运行方向正确，限速与目标速度有效，车长与轮径等信息有效。

::: details 常见缩写
| 缩写 | 全称 / 含义 |
| --- | --- |
| ADU | 状态显示单元 |
| AF-90x | AF-900 系列音频轨道电路 |
| ATC | 列车自动控制 |
| DID | 目的地 |
| EB | 紧急制动 |
