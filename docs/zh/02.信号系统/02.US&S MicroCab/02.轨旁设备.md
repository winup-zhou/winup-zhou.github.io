# US&S MicroCab 轨旁设备

二号线的轨旁 ATC 设备由三部分组成：**AF-902/AF-904 音频轨道电路**负责列车检测与机车信号发送，**MicroLok II** 完成轨道逻辑与联锁逻辑，**TWC 轨旁设备（TWCW）**承担与列车之间的非安全数据交换。此外，站台区域、车辆段与正线转轨处的 TWC 环线、道岔区的耦合单元等构成室外设备。

## AF-902/AF-904 音频轨道电路

### 概述

AF-902/904 是 ATC 系统的轨旁组成部分，同时提供**列车检测**与**数字机车信号传输**两项功能。设备从 MicroLok II 接收串行数据，加入本地的轨道电路识别信息后编码，通过钢轨发送给列车：

- 室内处理设备：机笼（Cardfile）及插接式轨道电路系统板（TCS）
- 轨旁设备：轨道耦合单元、350/500 MCM 钢轨连接线（Bond）与轨道环线

发送给列车的数据包括轨道电路 ID、目标速度、线路速度、目标距离、停车（berthing）、方向、下一机车信号载频、连挂/解钩与分岔信息等，全部经轨道传输并在车载 ATP 中解码。列车运行方向由 MicroLok II 报文中的 2 位方向控制位决定，AF-902/904 将"北"等同为"西"、"南"等同为"东"，只显示东、西方向；轨道电路总是布置成列车朝发送端行驶。

### 机笼与 TCS

| 项目 | 说明 |
| --- | --- |
| 安装方式 | 标准 19 英寸机架，电路板经背板母板互连 |
| 电源 | 两组 115 VAC ±10%（50/60 Hz）；主用单元由同一路电源供电，备用单元由第二路供电 |
| AF-902 | 每机笼两套**冗余**轨道电路，每半笼 2 块 TCS + 1 块电源板（为该套的主用、备用单元供电） |
| AF-904 | 每机笼四套**独立非冗余**轨道电路，4 块 TCS + 2 块电源板 |
| 功耗 | 每套轨道电路约 50 W，输入保护 10 A 熔断器 |
| 环境 | −25 ℃～70 ℃，湿度 95%（不凝露） |
| 配置存储 | 每块 TCS 在线 EEPROM：12 位轨道电路 ID、本地限速、MicroLok II 从站地址、IP 地址、载频、阈值电压等 |
| 通信 | 与 MicroLok II 采用串行链路（RS-485）或以太网，支持 MicroLok 串行协议与 MicroLok Peer 协议 |

TCS 前面板包含两行字符显示器（上行红色、下行绿色）、4 个回弹式拨动开关、系统复位按钮、18 个状态 LED 以及 2 个以太网口。以太网口既用于与 MicroLok II 通信，也提供本地网页界面。

### 频率分配与机车信号

机车信号载频共 8 个，从 9.5 kHz 到 16.5 kHz，步进 1 kHz，编号 F0～F7：

| 编号 | 频率 | 典型用途 |
| --- | --- | --- |
| F0 | 9.5 kHz | 特殊区段 |
| F1 | 10.5 kHz | 上行（西/北）方向 |
| F2 | 11.5 kHz | 下行（东/南）方向 |
| F3 | 12.5 kHz | 上行（西/北）方向 |
| F4 | 13.5 kHz | 下行（东/南）方向 |
| F5 | 14.5 kHz | 上行（西/北）方向 |
| F6 | 15.5 kHz | 下行（东/南）方向 |
| F7 | 16.5 kHz | 特殊区段 |

以 F1、F3、F5 为一组（上行）与 F2、F4、F6 为一组（下行）构成三频率循环。若两段相同载频的轨道电路无法以两段其他载频隔开，则允许以一段轨道电路加一组绝缘节隔开。

车载设备上有两个接收器，一个调谐到当前载频，另一个调谐到报文中给出的下一区段载频。列车接近钢轨连接线（Bond）时当前载频信号消失，一旦在下一载频上检测到有效数据与电平，车载设备即忽略旧载频数据、解码新数据，并重新调谐接收滤波器。

<img src="/signals/img/microcab/af-frequency.webp" alt="机车信号频率分配" width="688" />

### 列车检测

发送端发出的音频载波在接收端被接收，载波电平与数字报文同时被监视：

- 列车分路轨道电路时信号被阻断，接收到的信号低于预设阈值即判定为**占用**，并上报给联锁 MicroLok II
- TCS 将轨道信号显示为分路阈值的百分比：**≤100% 表示占用**，空闲时约为 162%（随道床条件变化而波动）
- 占用状态经 MicroLok Peer 报文（以太网）或 MicroLok 串行协议（RS-485）上报，同时由 VPO（安全并行输出）直流电压输出，可接入 MicroLok II 安全输入以获得更快的占用状态指示
- 列车跨压相邻两段轨道电路的分界点时，两段同时显示占用

| 轨道电路参数 | 数值 |
| --- | --- |
| 轨道电路长度 | 最大 305 m（1000 ft），最小 19.8 m（65 ft） |
| 分路灵敏度（S 型连接线） | < 0.25 Ω |
| 分路灵敏度（I 型连接线） | 10 ft（3 m）范围内 < 0.1 Ω |
| 耦合单元尺寸 | 16″W × 8″H × 10″L，可挂墙或落地安装 |
| 耦合单元至机笼 | ≤ 6000 ft（1830 m）双绞线（#14 AWG，特性阻抗约 100 Ω） |
| 耦合单元至环线 | ≤ 15 ft（5 m） |
| 钢轨连接线 | 350 或 500 MCM，阻抗约 1.0 Ω |
| 机车信号电流 | 9.5 kHz 时约 105 mA |

::: details 轨旁耦合方式
AF-902/904 不使用传统的阻抗联接器，而是以数米长的 350 或 500 MCM 电缆在两根钢轨之间接成"S"形，环线安装在"S"形的上、下两部分内侧。发送环线中的电流感应到"S"形电缆并加到钢轨上，钢轨上的电流也以同样方式感应到接收环线中。这种方式具有很强的方向性，其"前后比"由"S"形的长度与宽度之比决定。典型的耦合方式有 S 型、I 型、O 型连接线与直接注入（direct injection）四种，由机笼背面的方向继电器决定哪一侧发送、哪一侧接收。
:::

## TWC 轨旁设备

### 系统组成与接口

TWC（Train to Wayside Communications）系统分车载（TWCC）与轨旁（TWCW）两部分，实现车载系统与轨旁设备之间的**非安全、双向**数据交换。大部分数据在 CTC 与车载系统之间透传，TWCW 只做转发与缓冲。

<img src="/signals/img/microcab/twc-overview.webp" alt="TWC 系统关系示意" width="688" />

| 接口 | 参数 |
| --- | --- |
| 与 CTC / 轨旁 CPU | 全双工 RS-485 串行链路，4800 baud、无校验、1 位停止位，电平 ±2 V，US&S 标准协议（Genisys 子集） |
| 与 TWCC（车载） | 半双工 FSK 数据链路，经感应环线传输，4800 baud、无校验、1 位停止位；54 kHz 为 mark、64 kHz 为 space，电平可现场调整 |
| 电源 | 110 V AC |

通信为**半双工主从结构**：CTC 是 CTC—TWCW 链路的主站，TWCW 仅在收到请求时才发送；车载 TWCC 是车载—TWCW 链路的主站。每个 TWCW 在 SCC 板上以 DIP 开关设定唯一的节点地址（1～255），CTC 采用多点（multi-drop）方式访问。

TWCW 会缓冲收发的数据：收到有效报文时直接替换上一次的数据；链路静默超时后，缓冲区将被默认数据覆盖，以此协调两端不同的波特率与软件周期。

### 设备构成

<img src="/signals/img/microcab/twc-cardfile.webp" alt="TWC 轨旁机笼" width="688" />

| 板卡 | 型号 | 功能 |
| --- | --- | --- |
| RX/TX 板 | N451910-4606 | FSK 调制解调器，把 SCC 板的串行数据调制成载波发往环线，并把环线信号解调为串行数据 |
| SCC 板 | N451910-3204 | 微计算机，运行通信协议软件；前面板 RS-232 接口可接笔记本排故；背驮 SIA 子板提供 RS-485（对轨旁 CPU）与 RS-232（对 RX/TX 板）端口电路 |
| 电源板 | N451910-5101/5102 | 将 110 V AC 转换为 +24 V / +12 V / −12 V / +5 V DC，为同组板卡供电 |
| 电源控制板 | N21262502/21262501 | 2 个 LED 指示左/右侧 +12 V 是否正常，2 个开关分别控制左/右侧电源 |

机笼（N210069-03）可安装于标准 19 英寸通信机架，内含背板母板、110 V AC 输入端子、传输线端子与两个 9 针 RS-485 连接器（便于多台 TWCW 以菊花链方式接到同一轨旁 CPU）。一个机笼可带**两个环线**（A、B 组），每组由 RX/TX 板、SCC 板与电源板组成，机笼另附 4 块插接式屏蔽板用于板间抗干扰。每块电路板以 48 针（J1）与 96 针（J2）DIN 41612 连接器插接，前面板可见 LED、开关、调节电位器与连接器，并以两颗拇指螺钉固定。

数据流：车载天线 → 环线 → 耦合单元 → 传输线 → RX/TX 板 → RS-232 → SCC 板 → RS-485 → 轨旁 CPU；反方向数据则沿相反路径发送。耦合单元位于轨道旁箱内，为传输线提供阻抗匹配，可支持约 1.1 英里的传输线。

### 环线敷设

<img src="/signals/img/microcab/twc-wire-loop.webp" alt="环线安装示意" width="688" />

- 环线为一段 10 号绞合线，敷设在两根钢轨之间、距轨道中心 24 英寸（61 cm）
- 环线长度一般与站台长度一致，交叉（transposition）间距不超过 40 ft；在存车线（直接注入）上不超过 20 ft
- 环线可用钢卡固定在木质轨枕上；车载 ATC 通过检测载波在交叉点处的消失来判断列车位置

::: warning
环线安装时必须保证车载 ATC 与环线之间的电磁耦合不被覆盖在环线上方的任何金属物遮挡，也不允许其他设备的环线横跨本环线。这类干扰会影响通信，甚至被车载误判为交叉点，从而影响程序停车。
:::

### 连续发送模式（CTM）

TWC 支持列车自动程序停车。车载 ATC 在报文中给出预计到达时间（ETA）即可将环线所属的 TWCW 置入**连续发送模式（CTM）**：此时 TWCW 持续开启发射机，车载通过载波中断的位置识别环线交叉点。ETA 为 0 表示下一个 250 ms 通信周期仍保持半双工；CTM 一旦建立，车载无法再改变 TWCW 的工作模式，需由 CTC 以专门命令解除；ETA 时间到达后 TWCW 自动回到半双工模式。

CTM 状态下 TWCW 始终向列车发送缓冲区中最新的环线数据，因此跳停（Skip-Stop）等命令可随时下发给处在任意环线上的列车。

::: details 环线交叉点的安装要求
- 交叉点位置对程序停车的精度至关重要
- 交叉点位置表存储在**每一列**车上
- 交叉点移动超过 ±0.5 英寸可能就需要修改所有列车的软件表
- 敷设新环线时应预先考虑交叉点的最佳位置
- 新增或移动环线都必须修改车载软件表并重新测试
:::
