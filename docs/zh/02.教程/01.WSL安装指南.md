# 简明 WSL2 安装教程

## 何为 WSL
适用于 Linux 的 Windows 子系统（WSL）是 Windows 的一项功能, 可用于在 Windows 计算机上运行 Linux 环境, 而**无需单独的虚拟机或双系统**.   
WSL 旨在为想要同时使用 Windows 和 Linux 的开发人员提供无缝高效的体验.

---

## 系统要求
::: info 
- **Windows 10 版本 2004 及更高版本**（内部版本 19041 及更高版本）或 **Windows 11**
- 启用 **适用于 Linux 的 Windows 子系统** 功能
- 启用 **虚拟机平台** 功能
:::
::: warning 警告
如果您需要游玩三角洲行动等**带有 ACE 反作弊**的游戏, 则不可使用 WSL.    
可能会出现兼容性问题. 
:::
---

## 安装步骤

本文将以安装 [Ubuntu-22.04.5 LTS](https://apps.microsoft.com/detail/9pn20msr04dw) 发行版为例进行讲解. 

---
### 安装WSL的基本组件
::: tip
该操作需要质量较好的网络(可以流畅的连接到 GitHub)  
如果你的网络无法做到这点, 请事先下载以下文件:
::: navCard 2
```yaml
- name: Releases · microsoft/WSL
  desc: WSL2 安装程序 (文件名称为 wsl.2.x.x.x.x64.msi)
  link: https://github.com/microsoft/WSL/releases/latest # 可选
  img: https://learn.microsoft.com/zh-cn/windows/wsl/media/wsl-icon.svg
- name: Releases · dorssel/usbipd-win
  desc: USBIPD 安装程序 (文件名称为 usbipd-win_x.x.x_x64.msi)
  link: https://github.com/dorssel/usbipd-win/releases/latest # 可选
  img: https://github.com/fluidicon.png
```
:::


1. 按下 `Windows + R`, 在`运行`页面中输入 `powershell` 打开 **Powershell**, 以下指令需要在 **Powershell** 中执行. 

---

2. 输入下方命令进行 WSL 的安装  
::: info
如果你的网络质量不佳以至于无法连接到 GitHub, 直接将下面这一步替换为双击 **WSL2 安装程序(文件名称为 wsl.2.x.x.x.x64.msi)** 进行安装
:::

```powershell
wsl --install
```

3. 输入下方命令将 WSL 默认版本设置为 2

```powershell
wsl --set-default-version 2
```

<div align="center">
  <img src="/articles/tutorials/wsl-install/1.png" alt="将 WSL 默认版本设置为 2">
</div>


4. `(可选)`输入下方命令检查 WSL 内核的更新

```powershell
wsl --update
```

::: tip
后续可以用同样的指令接收 WSL 的有关更新. 
:::

5. 安装 USBIPD  
::: info
如果你的网络质量不佳以至于无法连接到 GitHub, 直接将下面这一步替换为双击 **USBIPD 安装程序(文件名称为 usbipd-win_x.x.x_x64.msi)** 进行安装
:::

```powershell
winget install --interactive --exact dorssel.usbipd-win
```

至此, 你已完成了 WSL 的基本组件的安装.

### 进行 Ubuntu 22.04.5 LTS 发行版的初次设置
::: tip
如果你因各种原因无法正常使用微软商店 (Microsoft Store), 请尝试使用 **Appx 文件提取网站**提取该发行版的 `.Appxbundle` 文件, 提取后在本地进行手动安装即可
:::

1. 打开你的微软商店 (Microsoft Store), 搜索 `Ubuntu 22.04.5 LTS`, 进行软件包获取和安装

<div align="center">
  <img src="/articles/tutorials/wsl-install/2.png" alt="Ubuntu 22.04.5 LTS 商店页面">
</div>

2. 安装完成后, 请在你的开始菜单中找到 Ubuntu 的图标, 点击进行初步安装.

<div align="center">
  <img src="/articles/tutorials/wsl-install/3.png" alt="在开始菜单中找到 Ubuntu 的图标">

点击后, 应当会弹出如下安装页面:  

<div align="center">
  <img src="/articles/tutorials/wsl-install/4.png" alt="安装页面">
</div>

当提示 `Enter new UNIX username` 时, 请设置 Ubuntu 的用户名(不必与电脑用户名相同, 且建议尽量简短). 

::: warning
Linux 对用户名的内容有要求, 请以**纯英文和数字**组成你的用户名.
:::

然后, 设置你的密码(需要输入两次)

::: warning
Linux 输入密码时, 密码是**不可见的**, 你需要牢记自己输入的内容.
输错了没关系, 回车之后它会让你重新输入.
:::

<div align="center">
  <img src="/articles/tutorials/wsl-install/5.png" alt="设置密码和用户名">

输入完成后, 终端弹出下列信息, 则代表初步安装已完成.

<div align="center">
  <img src="/articles/tutorials/wsl-install/6.png" alt="初步安装完成">
</div>

::: tip
Ubuntu 的组件和虚拟磁盘**默认放置在 C 盘**.  
如果你的 C 盘空间较为紧张, 可以考虑将虚拟磁盘文件放置到其他分区.  
例如, 将 Ubuntu 迁移到 D 盘 `D:\WSL\Ubuntu` 目录下:

```powershell
wsl --manage Ubuntu-22.04 --move D:\WSL\Ubuntu
```
:::

---
3. 执行下方命令将 Ubuntu-22.04 设为 WSL 的默认发行版:

```powershell
wsl --set-default Ubuntu-22.04
```

---
4. 进行 Ubuntu 语言的设置

我们进入 Linux 终端. 第一次启动 Ubuntu 需要刷新软件包源索引, 我们执行下方命令进行刷新:

```bash
sudo apt update
```

此时 Ubuntu 系统的默认语言为英文, 我们需要进行配置将其变为中文. 我们需要先安装 Ubuntu 的简体中文语言包:

```bash
sudo apt install language-pack-zh-hans -y
```

然后输入下方命令进行语言的重新配置:

```bash
sudo dpkg-reconfigure locales
```

你应当能够看到下面的页面（大概率是英文）, 用鼠标滚轮下滑: 

<div align="center">
  <img src="/articles/tutorials/wsl-install/7.png" alt="语言设置页面">
</div>
 
找到 `zh_CN.UTF-8 UTF-8`, 按下空格选中: 

<div align="center">
  <img src="/articles/tutorials/wsl-install/8.png" alt="选中中文">
</div>
 
按下Tab键让光标跳转到<确定>后, 按下回车, 进入默认语言选择页面: 

<div align="center">
  <img src="/articles/tutorials/wsl-install/9.png" alt="默认语言选择">
</div>
 
选中 `zh_CN.UTF-8`, 按下回车确定, 当提示 `Generation complete.` 后即完成语言配置.  

---
5. 之后, 请执行下方命令, 安装 Ubuntu 的一些 GUI 应用: 

```bash
sudo apt install gimp gedit nautilus x11-apps -y
```

后续若要启动 GUI 应用, 请到开始菜单中 Ubuntu-22.04 文件夹寻找对应应用: 

<div align="center">
  <img src="/articles/tutorials/wsl-install/10.png" alt="启动GUI应用">
</div>

--- 
6. 我们还需要进行一些 WSL 的网络设置, 请在开始菜单中搜索并点击 `WSL Settings`:

<div align="center">
  <img src="/articles/tutorials/wsl-install/11.png" alt="WSL Settings">
</div>
 
然后, 点击`网络`页面, 将你的网络设置为下图所示的参数: 

<div align="center">
  <img src="/articles/tutorials/wsl-install/12.png" alt="WSL网络设置">
</div>
 
若你不继续使用, 则在 Powershell 中输入下方命令将 WSL 关机: 

```powershell
wsl --shutdown
```

::: tip
关闭 WSL 的窗口并不意味着 WSL 关机, 它还会在后台保持运行并占用一定的系统资源. 
如果你需要让 WSL 彻底关机, 则在 Powershell 中输入上述命令即可
之后若要继续使用, 重新在终端中开启 Ubuntu 即可. 
:::
