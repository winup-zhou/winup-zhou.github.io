# vertah 東武车辆 定速+TASC/ATO全功能补丁

该补丁补全了车辆的ATO/TASC功能，增加了手柄的延迟显示，并追加了牵引2级定速功能。

## 安装方式

::: tip
在安装该补丁前，您应当先行安装vertah提供的东武9000/9050/50070系的车辆数据。
:::

将压缩包解压后，替换`Scenarios/vertah`路径下对应的文件即可完成安装。

## 操作说明

**按键**

::: info
仅涉及追加部分，其余部分请参照车辆原作者提供的信息。
:::

|功能|对应按键|
|:---:|:---:|
|ATO/TASC切换|`3`|
|ATO启动|`Insert`+`Delete`|
